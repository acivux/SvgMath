# SvgMath
C# (minimal effort)port if the Python SvgMath utility found at http://sourceforge.net/projects/svgmath/.

**Layout:** C# library in [`src/SvgMath`](src/SvgMath), test harness in [`test/SvgMathTest`](test/SvgMathTest), original Python 0.3.3 tree in [`src/reference/SVGMath-0.3.3`](src/reference/SVGMath-0.3.3) (reference only).

Version history: [`releasenotes.md`](releasenotes.md).
